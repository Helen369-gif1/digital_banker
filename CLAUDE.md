# digital_banker — общие правила для всех сайтов

В этой папке лежат отдельные сайты. Каждый — в своей папке и открывается из Атриума (`atrium-site`).

## Обязательно для каждого сайта: стрелка «Назад в Атриум»

- На каждой странице любого сайта, который открывается из комнаты Атриума, слева сверху стоит стрелка, возвращающая в Атриум.
- Это касается и всех новых сайтов, которые будут добавлены позже.
- Стрелка общая для всех сайтов, лежит в `shared/atrium-back.js`. Свою копию на сайте не делать.
- Как подключить к новому сайту: в конце `index.html`, перед `</body>`, добавить
  `<script src="../shared/atrium-back.js" defer></script>`
- Куда она ведёт, задаётся одной строкой `DEFAULT_HREF` в `shared/atrium-back.js`. Менять только там.
- Когда создаёшь новый сайт, подключай стрелку сразу и проверяй, что она не перекрывает шапку.
- Когда новый сайт становится комнатой Атриума, в `atrium-site/atrium.js` в блоке `rooms` у этой комнаты ставь `href` на его `index.html`, например `'../имя-папки/index.html'`.

## Общее

- Менять только то, что просит задача. Ничего не удалять и не переименовывать без разрешения.
- Правила внутри папки сайта (`CLAUDE.md` в `gia-site`, `global_reserve`) действуют дополнительно к этим.
- Commit и Push делает владелец сама через GitHub Desktop.
